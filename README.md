# travelwebsite2

Welcome to the Car Rental Service Website with an integrated Admin Panel.

## Features
- **Car Booking & Catalog**: Browse available cars, pricing, and details.
- **Admin Panel**: Manage cars, pricing, bookings, reviews, and website settings.
- **WhatsApp Integration**: Instant messaging templates for booking and inquiries.
- **Supabase Integration**: Real-time database updates and user authentication.
- **Tailwind CSS & Shadcn UI**: Clean, responsive, and modern user interface.

## Tech Stack
- Frontend: React (Vite + TypeScript)
- Styling: Tailwind CSS
- Database & Auth: Supabase
- Components: Radix UI / Shadcn UI

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up environment variables in `.env` (using `.env.example` as a template).
3. Run the development server:
   ```bash
   npm run dev
   ```
